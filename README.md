# Cooking Masterclass

A single-page Vue.js application that displays cooking workshops, allowing users to browse courses and save them to a wishlist.

## What the app does

- Browse available cooking courses with chef names, prices, and skill levels
- See if a course is available or sold out
- Save courses to a wishlist
- View wishlist count in the header
- Responsive design for desktop and mobile

## Built with

- Vue 3 (Composition API / `<script setup>`)
- Vite
- Custom CSS (artisanal craft aesthetic)

## Installation and run instructions

```bash
# Clone the repository
git clone https://github.com/your-username/LCA-VueJS-Exercises.git

# Navigate to project folder
cd LCA-VueJS-Exercises

# Install dependencies
npm install

# Run development server
npm run dev

```
