# Homes & Beyond

An interactive Vue.js property listings page for a Cape Town-based short-term rental startup, showcasing available properties with search, sort, and bookmark functionality.

![Screenshot](Screenshot.png)

## Features

- Dynamic property listings in a responsive grid layout
- Search bar that filters properties by title or location
- Sort toggle for price (low-to-high / high-to-low)
- "Not Available" badge on unavailable listings
- Bookmark/favourite toggle functionality
- Header with brand name and total property count

## Tech Stack

- Vue.js 3
- HTML/CSS
- Bootstrap
- JavaScript

## Installation & Setup

1. **Clone the repository**

```bash

# Clone the repository

git clone https://github.com/your-username/LCA-VueJS-Exercises.git

# Navigate to project folder

cd LCA-VueJS-Exercises

# Install dependencies

npm install

# Run development server

npm run dev

```
