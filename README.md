# Cape Town Food Fest

An interactive Vue.js landing page for an annual outdoor food festival, showcasing ticket tiers with option for modern e-commerce feature implementation.

![Screenshot](Screenshot.png)

## Features

- Dynamic ticket cards (Bronze, Silver, Gold)
- Featured tier (Silver) with emphasized styling
- Favourite toggle functionality
- Fully responsive design

## Tech Stack

- Vue.js 3
- HTML/CSS
- Bootstrap
- JavaScript

## Project structure

```bash
src/
├── assets/
│   └── global.css
├── components/
│   ├── Header.vue
│   ├── TicketCard.vue
│   └── TicketGrid.vue
├── App.vue
└── main.js

```

## Installation & Setup

1. **Clone the repository**

```bash

# Clone the repository

git clone https://github.com/your-username/LCA-VueJS-Exercises.git

# Navigate to project folder

cd LCA-VueJS-Exercises

# Install dependencies

npm install

# Run development server

npm run dev

```
